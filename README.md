I'm a full-stack developer and MSc student in **Geoinformatics & Spatial Data Science** at the Institute for Geoinformatics (ifgi), University of Münster. I like building web apps for open-source environmental data platforms and educational technology.

### 🔭 What I'm working on
- Building new features for **[openSenseMap](https://opensensemap.org/)**, the open environmental sensor-data platform, at opensenselab.
- Teaching assistant for the **Python in QGIS & ArcGIS** course at ifgi.

### 🌱 Recently built
- **[openSenseMap-edu](https://github.com/JerryVincent/opensensemap-edu)** — an interactive web-based tool for learning SQL with real environmental sensor data. Built as my master's thesis (Spring Boot + a sandboxed SQL editor over live sensor data).
